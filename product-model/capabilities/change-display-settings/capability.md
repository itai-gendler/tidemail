# Change display settings

Change how TideMail looks and behaves in Settings → Display, saved with Ctrl+S: theme, icons, tag style and colors, dates, mark-read behavior, focus line, sender column, conversation threading, unread and starred ordering, links, reading width, browser, density, headers, images, desktop notifications, mouse support and quit confirmation. The theme picker (`T`) changes the theme directly.
